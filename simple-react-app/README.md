# 🚀 Mini Support Ticket Board

Built for teams that want to resolve issues, not fight with their tools. This full-stack application provides a seamless experience for tracking, managing, and resolving internal support tickets with zero clutter.

## ✨ Why You'll Love It

- **Instant Visibility:** See everything at a glance with our intuitive summary dashboard.
- **Lightning Fast:** Built on React and Express for near-instant load times and real-time updates.
- **Zero Clutter:** A beautifully clean UI that focuses on exactly what you need—solving problems.
- **Bulletproof Reliability:** Data securely persisted in MongoDB, ready for the cloud.

## 🛠️ The Tech That Powers It

- **Frontend:** React 18, TypeScript, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Local or Atlas)
- **Design:** Custom, responsive CSS


### 1. Start the Backend
cd backend
npm install
npm run seed  
npm start
```
*Backend runs on `http://localhost:3001`*

### 2. Start the Frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:5173`*
